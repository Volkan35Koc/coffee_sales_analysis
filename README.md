# Coffee Sales Analysis 

This project presents an **exploratory data analysis (EDA)** of coffee shop sales transactions.  
The objective is to uncover sales trends, evaluate product category performance, and identify temporal patterns in customer purchasing behavior.  

The analysis is designed with a **business-oriented perspective**, supporting data-driven decision making for retail operations.  

## 📊 Project Scope

- **Data Preparation & Cleaning**  
  - Merging transaction date and time into a single timestamp  
  - Creating calculated fields such as total sales per line item  
  - Data quality validation (missing values, duplicates, negative prices/quantities)  

- **Exploratory Data Analysis**  
  - Transaction-level aggregation (basket size, number of line items, total revenue)  
  - Product category performance analysis  
  - Daily sales trends and moving averages  
  - Hourly sales patterns  
  - Weekday & hour heatmap analysis  

- **Visualization & Reporting**  
  - Business-friendly dashboards and charts (bar, time series, heatmap)  
  - Export of results to **CSV** and **PNG** for further reporting
